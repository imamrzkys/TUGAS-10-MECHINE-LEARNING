# TA-10 KNN Student Status Prediction (Flask)

Project website for predicting student status (Dropout / Enrolled / Graduate) using a pre-trained KNN model.

Quick structure

project/
│ app.py
│ requirements.txt
│ Procfile
│ runtime.txt
│ /models
│   model.pkl  <-- place trained model here
│   preprocessor.pkl  <-- place preprocessor pipeline here
│   label_encoder.pkl (optional)
│ /templates
│ /static

Setup and run locally

1. Create a virtualenv (recommended) and activate it.
2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Put your trained `model.pkl` and `preprocessor.pkl` into the `models/` folder.
4. Run the app:

```powershell
python app.py
```

Open http://127.0.0.1:5000

Deploy to Railway

1. Create a new Railway project and link your Git repo (or push this folder).
2. Railway will detect Python; ensure the `Procfile` and `requirements.txt` are present.
3. In Railway environment variables, set `FLASK_SECRET` to a secure value.
4. Deploy — Railway uses `gunicorn app:app` from `Procfile`.

Notes

- This repo does not include your trained model files. Place `model.pkl` and `preprocessor.pkl` produced during training into `/models` before using the prediction feature.
- Save any images generated by `TA10.ipynb` into `/static/img` to display them on the site.
